# ai-workspace

**Одно рабочее пространство для всех нейросетей.** ChatGPT, Claude, Codex, Grok, Kimi, Qwen, ZCode — пользуйся любой
и пересаживайся между ними, не теряя ни правил, ни памяти, ни скилов, ни подключений, ни истории проектов.

[English version →](README.en.md)

---

## Зачем

Обычно всё важное живёт **внутри** конкретной нейросети: инструкции в её настройках, память в её облаке,
скилы в её папке, переписки в её истории. Заблокировали аккаунт, вышла модель лучше, просто захотелось
сменить — и всё начинается с нуля.

ai-workspace переворачивает схему: **всё лежит у тебя в одной папке в открытых форматах (markdown, JSON)**,
а нейросети к ней только подключаются. Сменил нейросеть — подключил новую к той же папке, и она
сразу знает, кто ты, как с тобой работать и где вы остановились в каждом проекте.

## Что получаешь

```
~/AI/
├── rules/core.md        как со мной работать — правила для любой нейросети
├── memory/profile.md    кто я и чем занимаюсь — досье
├── skills/              скилы (открытый формат SKILL.md)
├── mcp/servers.json     подключения (MCP) — без ключей внутри
├── projects/            проекты; в каждом:
│   └── Проект/
│       ├── AGENTS.md        карта проекта для ИИ
│       ├── СТАТУС.md        где мы сейчас
│       └── летопись/        что делали, кто, когда и почему
├── chats/               архив выгрузок ChatGPT/Claude (по желанию)
└── prompts/             служебные промпты
```

Одна команда `aiw sync` (и каждый вечер сама) раскладывает это по нейросетям:

| | Правила и досье | Скилы | Доступ к файлам (MCP) | Летопись |
|---|---|---|---|---|
| **Claude Code** | `~/.claude/CLAUDE.md` | ✓ | ✓ | ✓ хук сам требует записать |
| **Claude Desktop** | текст для настроек | — | ✓ | по правилу |
| **Codex** | `~/.codex/AGENTS.md` | ✓ | ✓ | по правилу |
| **Grok Build** | `~/.grok/AGENTS.md` | ✓ (читает скилы Claude и `~/.agents`) | ✓ | по правилу |
| **Kimi Code** | `~/.kimi-code/AGENTS.md` | ✓ (`~/.agents/skills`) | ✓ | по правилу |
| **Qwen Code** | `~/.qwen/QWEN.md` + чтение `AGENTS.md` в проектах | ✓ | ✓ | по правилу |
| **ZCode и другие агенты** | `AGENTS.md` в папке проекта | — | — | по правилу |
| **ChatGPT, Grok (веб)** | текст ≤ 1500 символов в инструкции | — | — | выдаёт запись текстом |
| **Kimi, Qwen Chat, Meta AI (веб)** | сообщения для «памяти» | — | — | выдаёт запись текстом |

Агенты подключаются, только если установлены: поставил Grok Build или Qwen Code позже — следующий
`aiw sync` подключит его сам. Meta AI доступен не во всех странах, а инструкций, кроме памяти, у него нет.

## Безопасность по умолчанию

- **Ключи и пароли никогда не лежат в пространстве.** Для MCP — `aiw secret set ИМЯ` (Связка ключей macOS,
  системное хранилище или `~/.secrets` с правами только для тебя), в конфиге — ссылка `"secret:ИМЯ"`.
- **В git-бэкап уходит только ядро** (правила, досье, скилы, настройки). Проекты и ключи — никогда.
- **Перед каждым коммитом — проверка на токены и приватные ключи.** Нашлось похожее — коммит отменяется.
- **Чужие файлы не затираются:** если на месте ссылки уже был твой файл или скил — он уходит в `.aiw/backups/`,
  а скилы, созданные прямо в нейросетях, забираются в `skills/`.
- Нейросетям прописано правило не читать `.secrets`, `.env` и ключи без прямой просьбы.

## Установка

**macOS / Linux** — в Терминале:
```bash
curl -fsSL https://raw.githubusercontent.com/sobolevandrey/ai-workspace/main/install.sh | bash
```

**Windows** — в PowerShell:
```powershell
irm https://raw.githubusercontent.com/sobolevandrey/ai-workspace/main/install.ps1 | iex
```

Установщик сам поставит недостающее (git, Python; Node.js — по согласию), спросит язык, папку и имя,
создаст пространство и подключит его к найденным нейросетям. Движок живёт отдельно в `~/.ai-workspace`,
твои данные — в `~/AI`, поэтому обновления никогда не трогают твои файлы.

## После установки — 3 шага

1. **Заполни о себе.** `~/AI/memory/profile.md` (кто ты, проекты, инструменты) и при желании поправь
   `~/AI/rules/core.md` (как тебе отвечать). Можно попросить любую нейросеть помочь.
2. **Запусти `~/AI/aiw sync`** и вставь тексты из `~/AI/.aiw/out/` в веб-версии:
   - **Claude** → Настройки → инструкции для Claude ← `custom-instructions.txt` (уже в буфере обмена);
   - **ChatGPT** → Настройки → Персонализация → Пользовательские инструкции ← `chatgpt.txt`;
   - **Grok** → Настройки → Customize → инструкции ← `chatgpt.txt`;
   - **Kimi, Qwen Chat, Meta AI** и другие с «памятью» → сообщениями в чат ← `memory-messages.txt`.
3. **Работай в проектах.** `~/AI/aiw new-project Название` (группа: `Клиенты/Название`) и открывай папку
   проекта в Codex, Claude, Kimi, ZCode — они прочитают карту, статус и летопись.

## Команды

| Команда | Что делает |
|---|---|
| `aiw sync` | Раскладывает правила, скилы, хук, MCP; делает бэкап. Каждый вечер в 21:07 запускается сама |
| `aiw new-project Имя` | Новый проект из шаблона (`Группа/Имя` — проект в группе) |
| `aiw secret set ИМЯ` | Сохранить ключ для MCP-подключения |
| `aiw doctor` | Проверка установки: что найдено и настроено |
| `aiw check` | Долги летописи и раздувание по проектам (ничего не меняет) |
| `aiw update` | Обновить ai-workspace (твои файлы не трогаются) |
| `aiw import-chats` | Экспорт ChatGPT/Claude из `chats/_raw/` → markdown-архив |
| `aiw uninstall` | Отключить от нейросетей. Данные остаются |

`aiw` — это `~/AI/aiw` (на Windows `~/AI/aiw.cmd`).

## Проекты: статус и летопись вместо хранения переписок

Хранить все переписки — шум. Вместо этого у каждого проекта два файла (подход как у Anthropic с
progress-файлом для долгих агентов и Memory Bank в Cline):

- **`СТАТУС.md`** — где мы сейчас: что в работе, что блокирует, следующий шаг. Перезаписывается.
- **`летопись/ГГГГ-ММ.md`** — короткая запись о каждой содержательной сессии: когда, какая нейросеть, зачем,
  что сделано, какое решение и почему, какие файлы. Только дописывается.

Любая нейросеть в начале читает статус и последние записи, в конце — обновляет. Claude Code это
делает принудительно (хук). Если установлен [SpecStory](https://specstory.com), полные переписки
агентов тоже сохраняются в проект автоматически.

## Ночная проверка: система чинит себя сама

Нейросети забывают. Поэтому каждый вечер `aiw sync` сравнивает, что менялось в каждом проекте, с тем,
что записано, и вписывает в начало `СТАТУС.md` блок «⚠ Требует внимания»: работа без записи, статус
отстаёт от летописи, прошлый месяц не подытожен, файл раздулся. Любая нейросеть читает статус первым —
и сначала закрывает долг. Закрыт — блок исчезает сам. Сводка по всем проектам — в `ПРОЕКТЫ.md`.

## Через два года не станет монструозным

В каждый разговор попадает только малое: правила и досье (бюджет ~6000 символов), `СТАТУС.md`
(≤ 1 страницы), `ИТОГИ.md` и 2–3 последние записи. Остальное лежит, но в контекст не грузится.

| Что растёт | Как держится в узде |
|---|---|
| Летопись | файл на месяц; раз в месяц — итоги в 5–10 строк в `летопись/ИТОГИ.md` |
| `СТАТУС.md`, `AGENTS.md` | лимиты строк, проверка предупреждает о раздувании |
| Правила и досье | бюджет символов; узкие правила — в скилы (грузятся только по делу) |
| Скилы | предупреждение после 60 штук; неактуальные — в `skills/_архив/` |
| Проекты | `ПРОЕКТЫ.md` с последней активностью; без активности > 90 дней — кандидаты в `projects/_архив/` |

## Скилы и подключения

- Нашёл скил — попроси нейросеть положить его в `~/AI/skills/<имя>/` и запусти `aiw sync`: он появится
  в Claude и Codex. Скил, поставленный прямо в Claude/Codex, `aiw sync` сам заберёт в `skills/`.
- Подключения (MCP) описываются один раз в `~/AI/mcp/servers.json` и раскладываются в Claude Desktop,
  Claude Code и Codex. По умолчанию подключён доступ к самой папке `~/AI`.

## Бэкап — честно

| Что | Чем |
|---|---|
| Ядро: правила, досье, скилы, настройки | приватный репозиторий GitHub (установщик предложит создать) |
| Проекты и ключи | **Time Machine** / облачный бэкап (Backblaze, Arq) / File History на Windows |

GitHub не для всего: файлы больше 100 МБ он не принимает, а ключам не место в git даже в приватном
репозитории. Без бэкапа проектов смерть ноутбука = потеря проектов.

## Сменить нейросеть — чек-лист

1. Новая нейросеть с доступом к файлам → открой в ней папку проекта (или `~/AI`). Всё.
2. Веб-версия → вставь текст из `~/AI/.aiw/out/` в её настройки.
3. Новый инструмент со своими папками для правил/скилов → добавь пути в `aiw.py` (или открой issue).

## Требования

macOS 12+, Linux (systemd или cron), Windows 10/11. Python 3.9+, git. Node.js — для доступа к файлам из Claude Desktop.
Протестировано на macOS и Linux; Windows-часть написана по документации — сообщай о проблемах.
