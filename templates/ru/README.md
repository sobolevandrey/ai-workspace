# Моё рабочее пространство для нейросетей

Здесь лежит всё, что не должно зависеть от конкретной нейросети: правила, досье, скилы,
подключения, проекты и их история. ChatGPT, Claude, Codex, Kimi, ZCode и будущие инструменты
только подключаются к этой папке. Поменял нейросеть — ничего не потерял.

| Папка | Что внутри |
|---|---|
| `rules/core.md` | **Как со мной работать** — главные правила для любого ИИ |
| `memory/profile.md` | **Кто я и чем занимаюсь** — досье |
| `skills/` | Мои скилы (формат SKILL.md) |
| `mcp/servers.json` | Подключения (MCP). Ключи — не здесь, а через `aiw secret set` |
| `projects/` | Проекты: у каждого `AGENTS.md`, `СТАТУС.md`, `летопись/` |
| `chats/` | Архив выгрузок ChatGPT/Claude (по желанию) |
| `prompts/` | Служебные промпты |
| `.aiw/` | Служебное: сгенерированные тексты, бэкапы, лог |

## Команды
```
./aiw sync                 разложить всё по нейросетям (и так каждый вечер само)
./aiw new-project Имя      новый проект («Клиенты/Имя» — проект внутри группы)
./aiw secret set ИМЯ       сохранить ключ для MCP
./aiw doctor               проверка
./aiw update               обновить ai-workspace
```

## Правила жизни
1. Результат работы — файлом в проекте, а не только в чате.
2. Сессия в проекте → запись в `летопись/` + обновлённый `СТАТУС.md`.
3. Правила меняешь только в `rules/core.md`, о себе — в `memory/profile.md`, потом `./aiw sync`.
4. Ключи и пароли — только в `~/.secrets` / `aiw secret set`, никогда в этой папке.
