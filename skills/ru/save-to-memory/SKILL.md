# Сохранить в память

1. Что сохраняем:
   - устойчивый факт о пользователе / предпочтение → `memory/profile.md` (нужный раздел);
   - контекст проекта → `memory/projects/<проект>.md`;
   - решение или итог работы по проекту → летопись проекта (скил `project-chronicle`).
2. Коротко, одна-две строки, без дублей.
3. Никогда не сохраняй пароли, ключи, номера карт и документов.
4. Покажи, что и куда записал. Если менялся `memory/profile.md` — напомни запустить `aiw sync`.

Нет доступа к файлам — выдай готовый текст и укажи файл, куда его вставить.
