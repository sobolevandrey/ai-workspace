# Установка через нейросеть (без Терминала)

Открой приложение нейросети, которое умеет работать с файлами на твоём компьютере
(Codex, Claude с доступом к компьютеру, Kimi Work, ZCode и т. п.), и отправь ей это сообщение целиком:

```
Установи мне ai-workspace — систему, которая хранит мои правила, память, скилы и проекты
в одной папке для всех нейросетей. Репозиторий: https://github.com/sobolevandrey/ai-workspace

1. Спроси, как меня зовут. Определи мою систему и выполни установку в терминале:
   • macOS / Linux:
     curl -fsSL https://raw.githubusercontent.com/sobolevandrey/ai-workspace/main/install.sh | bash -s -- --yes --lang ru --name "МОЁ ИМЯ"
   • Windows (PowerShell):
     & ([scriptblock]::Create((irm https://raw.githubusercontent.com/sobolevandrey/ai-workspace/main/install.ps1))) --yes --lang ru --name "МОЁ ИМЯ"
   Если понадобится пароль от компьютера или появится окно установки — объясни простыми
   словами, что нажать, и подожди меня. Пароль мне не пересказывай и не проси.
2. Когда установка закончится, открой файл ~/.ai-workspace/skills/ru/aiw-onboarding/SKILL.md
   и выполни его: проведи со мной короткое интервью и настрой систему под меня.

Говори со мной просто, без технических терминов. Ничего не удаляй без моего согласия.
```

Если нейросеть отвечает, что не может выполнять команды, — это веб-версия без доступа
к компьютеру. Открой её настольное приложение с доступом к файлам или поставь вручную
по README (одна команда в Терминале).
